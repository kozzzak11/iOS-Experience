# iOS Experience — Android

Личный проект для Nothing Phone (4a), Android 16 / Nothing OS. Kotlin, InputMethodService, Compose-настройки. Без root, сети, рекламы и аналитики.

[Скачать APK 0.1.0](https://github.com/kozzzak11/iOS-Experience/releases/download/v0.1.0/iOS-Experience.apk) · [Успешная проверка Android 16](https://github.com/kozzzak11/iOS-Experience/actions/runs/39510468341)

## Первый выпуск: Keyboard 0.1.0

Реализовано в коде:
- Настоящая Android IME: русская и английская раскладки, цифры/символы, телефонное/числовое поле.
- Shift, двойной Shift → Caps Lock, заглавная в начале предложения, редакторские действия Send/Search/Next/Done и перенос строки.
- Долгое удаление, перемещение курсора на пробеле, альтернативные символы (е → ё, ь → ъ, акценты), пунктуация.
- Оформление в духе iOS: скруглённые клавиши, предпросмотр нажатия, тактильная отдача, системный звук Android, светлая/тёмная/системная тема, настройка высоты.
- Кнопка скрытия, системный Back; опциональный свайп вниз внутри клавиатуры (по умолчанию выключен).
- Локальные подсказки RU/EN, дополнение слова, ограниченная автокоррекция с однозначным ответом. Автокоррекция по умолчанию выключена. Встроенные словари небольшие; предсказание фраз и swipe typing не реализованы.
- Личный словарь с ручным добавлением, без автоматического обучения введённому тексту.
- Панель Emoji: 3944 последовательности Unicode 17.0, категории, поиск по английским названиям/нескольким русским словам, recent, оттенки кожи при удержании.
- Пароли и режим IME_FLAG_NO_PERSONALIZED_LEARNING: без чтения окружающего текста, composing, подсказок, автокоррекции и предпросмотра символов.
- Общее приложение настроек с рабочими Keyboard / Emoji / Appearance и полями для проверки.

**Emoji используют системную графику Android. Apple Emoji в выпуске 0.1.0 отсутствуют.** Изображения Apple и Apple Color Emoji не включены. Отправляется Unicode — рисунок в стороннем приложении выбирает это приложение.

Launcher, системные gestures и оформление домашнего экрана ещё не реализованы; пустых переключателей для них в приложении нет. Весь проект не объявляется завершённым после одного модуля.

## Установка и возврат
1. Установить APK, открыть iOS Experience.
2. «1. Включить клавиатуру» открывает официальный список IME Android. Включить iOS Keyboard.
3. «2. Выбрать клавиатуру» открывает официальный системный переключатель. Выбрать iOS Keyboard.
4. Проверить ввод в тестовом поле, затем в нужных приложениях.

◎ меняет RU/EN, удержание ◎ открывает список других IME. ☺ открывает emoji. ⌄ скрывает клавиатуру. Удерживайте пробел и двигайте палец горизонтально для курсора. Двойной Shift включает Caps Lock, одиночный выключает его.

Для возврата к прежней клавиатуре выбрать её в системном переключателе, затем отключить iOS Keyboard в списке Android. Удаление приложения не требует сброса телефона. Настройки словаря и recent очищаются кнопкой сброса в приложении.

## Сборка
Требуется JDK 17, Android SDK Platform 36. Открыть папку в Android Studio или выполнить:

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Для интеграционной проверки на Android 16 эмуляторе/устройстве:

```bash
./gradlew connectedDebugAndroidTest
```

`.github/workflows/android.yml` сначала компилирует приложение, запускает unit tests и lint, затем отдельным job запускает Android 16 emulator test. APK и отчёты сохраняются в Actions Artifacts. После успешного build и Android 16 emulator job отдельный job публикует APK в GitHub Releases (v0.1.0). Последняя проверенная сборка доступна в разделе Releases репозитория.

Debug APK предназначен для личной разработки. Локальная сборка и GitHub Actions могут подписываться разными development-сертификатами. Для обновлений поверх установленной версии нужен постоянный ключ. Release signing пока не настроен; приватные ключи в репозиторий не добавляются.

## Проверки и ограничения
Актуальные фактически выполненные проверки указаны в `docs/VERIFICATION.md`. Наличие теста в исходниках не означает его успешный запуск. На физическом Nothing Phone (4a), в Telegram, WhatsApp, Chrome и ChatGPT тестирование ещё не проводилось.

Подробности: `docs/PLATFORM-LIMITS.md`, `docs/ROADMAP.md`.

## Конфиденциальность
В manifest нет INTERNET, доступа к файлам, микрофону, accessibility или overlay. Ввод не логируется и не сохраняется. Текущее слово обычного редактора существует только в RAM для composing; при завершении сессии очищается. В настройки записываются только настройки, вручную добавленный словарь и разрешённые пользователем недавние emoji. Резервное копирование приложения отключено.

Встроенные словари — небольшой вручную составленный стартовый набор. Данные Unicode используются по Unicode License v3, полный текст: `docs/licenses/UNICODE.txt`. Графика Apple не распространяется. Шрифты, системные звуки и emoji-рисунки предоставляет установленная система Android.
